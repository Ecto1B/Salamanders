# Salamanders Forge Command

A tactical mobile command system for Warhammer 40K Salamanders armies.

## Features
- Army builder
- Turn + phase tracker
- Dice engine
- Cloud sync
- Model tracking support
- Animated Forge Mode UI

## Official App
Uses reference data via:
https://www.warhammer40000.com/app/

## Note
Does not scrape or redistribute official rules from Games Workshop.
